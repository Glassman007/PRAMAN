  - removed an unused local helper.

  - narrowed dead internal-only exports while keeping all runtime behavior.

  - removed an unused alias helper; retained live PRAMAN route/link contracts.

- unused projection/data helpers and dead exports;
- obsolete distortion-node CSS;
- stale Stage 1–5 validation/smoke artifacts;

Production source was re-searched after cleanup. No production implementation remains for `previousStage`, `nextStage`, `phaseSlides`, `stageCards`, `renderStage`, `demoNodes`, `sampleFlow`, `mockEvidence`, `lifecycleSteps`, `Next Stage`, or `Previous Stage`.
