Preferred Layer 1 integration
=============================

If the Layer 1 Unified GIS Map control is an <a> element:

  <a href="./layer2_unified_gis/index.html">Unified GIS Map</a>

If it is a <button> element:

  document.querySelector('#YOUR_UNIFIED_GIS_BUTTON_ID')
    .addEventListener('click', () => {
      window.location.href = './layer2_unified_gis/index.html';
    });

Fallback without changing existing button logic:

  <script src="./layer2_unified_gis/layer1-integration.js"></script>

Place the layer2_unified_gis folder at the same project-root level as the Layer 1 index.html for these relative paths.
