Layer 2 city-layout update

Replace your existing Layer 2 webgl-map.js with this file.
Copy the included assets/ directory into Layer 2 beside index.html.

Changes:
- Removed the old five-row parcel clamp that caused later parcels to overlap/go off-screen.
- Layout now scales from DATA.parcelsGeoJSON.features, so every parcel in the dataset is rendered.
- For 128 canonical parcel features, all 128 buildings receive unique lots in a 4x4 city-block layout.
- Added major roads between city blocks and narrow access roads between buildings.
- Added up to four circular parks at road intersections.
- Added billboard trees inside the parks using the supplied green and pink tree references.
- Parcel IDs remain at ground/floor level with no label background.
- Existing parcel selection, source comparison, conflicts, camera orbit/zoom and boundary compare behavior remain intact.
